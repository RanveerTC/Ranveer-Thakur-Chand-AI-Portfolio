# ITAI 1378 - Computer Vision Labs

Labs and assignments from ITAI 1378 (Computer Vision), part of the Applied AI & Robotics program at Houston Community College. The labs move from foundational image processing to classic ML on images, then to CNNs and transfer learning for object detection and segmentation.

## Labs

### [A01 - Colab and Other Tools Practice Run](./A01%20ITAI%201378%20Colab%20and%20other%20Tools%20Practice%20Run)
Practice run through Google Colab and the course toolchain before starting actual CV work.

### [A02 - Image Processing Adventure Quest](./A02%20Image%20Processing%20Adventure%20Quest)
Group project (Group 08) applying point, neighborhood, and geometric image operations using OpenCV and Pillow.

### [L01 - Exploring Real-World Applications of Computer Vision](./L01%20Exploring%20Real-World%20Applications%20of%20Computer%20Vision)
Research and reflection on where CV is used in industry (medical imaging, autonomous vehicles, facial recognition, etc.) before writing any CV code.

### [L02 - Image Processing Lab: From Pixels to Perception](./L02_RanveerChand_ITAI1378)
Hands-on lab implementing fundamental image processing operations from scratch, then with OpenCV/Pillow, to see how images become numerical matrices.

### [L03 - Classic ML for Image Classification](./L03%20Using%20Classic%20ML%20in%20Computer%20Vision)
Classified CIFAR-10 images using an SVM (linear and RBF kernels), comparing classification reports side by side to see how kernel choice affects performance.

### [L04 - Chihuahua or Muffin (Classic ML)](./L04%20Chihuahua%20or%20Muffin)
Tackled the classic chihuahua-vs-muffin visual discrimination problem using a classic ML approach, as a baseline for L05.

### [L05 - Chihuahua or Muffin (CNN)](./L05%20Chihuahua%20or%20Muffin%20with%20CNN)
Revisited the same classification problem with a CNN, to compare against the classic ML baseline from L04.

### [L06 - Object Detection & Segmentation with Transfer Learning](./L06%20Object%20Detection%20using%20Transfer%20learning)
Used a pretrained model adapted via transfer learning to perform object detection and segmentation, instead of training from scratch.

## Technologies Used
Python, OpenCV, Pillow, NumPy, Matplotlib, Scikit-Learn, TensorFlow/Keras, Google Colab
