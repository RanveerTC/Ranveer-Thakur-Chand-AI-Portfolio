# ITAI 1371 - Machine Learning Labs

Labs and assignments from ITAI 1371 (Machine Learning), part of the Applied AI & Robotics program at Houston Community College. The labs move from ML fundamentals and workflow, through EDA and data preparation, to regression/classification, model evaluation, and the bias-variance tradeoff - mostly using the Titanic dataset as a running example.

## Labs

### [L02 - ML Development Tools](./L02%20ML%20development%20tools)
Contribution journal documenting hands-on exploration of the ML development environment and toolchain used for the rest of the course.

### [L03 - ML Workflow and Types of Learning](./L03%20Lab%20ITAI%201371)
Walked through the full ML workflow (data prep, feature selection, splitting, training, evaluation) and built a first classification model using the Wine dataset.

### [Lab 04 - Exploratory Data Analysis](./Lab%2004%20Exploratory%20Data%20analysis)
Practiced descriptive statistics and visual EDA (Matplotlib/Seaborn) on the Titanic dataset - survival by class, gender, age, and port of embarkation.

### [Lab 05 - Data Preparation](./Lab%2005%20Data%20Preparation)
Imputed missing values, one-hot encoded categorical columns, and scaled numeric features on the Titanic dataset to prepare it for modeling.

### [Lab 06 - Regression and Classification](./Lab%2006%20Regression%20and%20Classification)
Trained a Linear Regression model to predict fare and a Logistic Regression model to predict survival on the Titanic dataset.

### [Lab 07 - Model Evaluation](./Lab%2007%20Model%20evaluation)
Went beyond accuracy using a confusion matrix, precision/recall/F1, and 5-fold cross-validation to evaluate a classification model.

### [Lab 08 - Bias-Variance Tradeoff](./Lab%2008%20Bias%20Variance%20Tradeoff)
Trained polynomial regression models of varying complexity and plotted learning curves to visualize underfitting, overfitting, and the bias-variance tradeoff.

### [Midterm - Exploratory Data Analysis](./Mid%20Term%20-%20Exploratory%20Data%20Analysis)
Group project performing a full EDA and leakage-free preprocessing pipeline on the Rajasthan Heatwave dataset.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, imbalanced-learn
